# Meteorite landings — data mining & visualisation

Exploratory analysis of NASA's meteorite landing records: **45,716 records** spanning
860–2013, with mass, fall/find status, classification, year and coordinates.

The project is a reproducible `uv` project: the dataset lives in `data/raw/`, every new
figure is generated by code in `src/`, and prior exploration is archived under `docs/`.

## Layout

```
.
├── data/raw/                  # cleaned source dataset (do not edit by hand)
├── docs/
│   ├── analysis.md            # analysis of the new figures 04-11 (numbers + interpretation)
│   └── exploration/           # 28 early quick-look screenshots + index
├── figures/                   # all output figures (01-11)
├── src/meteorite_landing_data_mining/
│   ├── common.py              # paths, palette, loading, region & family enrichment
│   ├── cli.py / __main__.py   # one-command regeneration
│   └── figures/               # one module per new figure
├── pyproject.toml             # dependencies and CLI entry point
└── uv.lock
```

## Quickstart

```bash
uv sync                                          # create the environment
uv run python -m meteorite_landing_data_mining   # regenerate figures 04-11
```

or via the installed script:

```bash
uv run meteorite-landing-data-mining
```

> **Note:** `files.pythonhosted.org` is unreachable from this network, so
> `pyproject.toml` pins the Aliyun PyPI mirror as the default index. Remove that block if
> your network can reach PyPI directly, then re-run `uv lock`.

## Key findings

- **Collection geography, not falling statistics.** 69.1 % of geolocated records are from
  Antarctica; the top three recovery regions (Antarctica, Arabia/Oman, Sahara) hold 86.8 %.
  The 2010s are led by Arabia (42 %) and the Atacama (32 %) as Antarctic collecting slowed.
- **Mass is a power law.** 605 t total, but Hoba alone is 9.9 % and the top 10 records are
  57.1 % — all giant irons; Sikhote-Alin (23 t) is the only observed fall among them.
- **87.2 % of all records are ordinary chondrites**, yet 77.2 % of observed falls are too —
  finds, not rarity, drive the chokehold of that family.
- **A regime break around 1970:** irons drop from ~42 % (1900s) to <1 % (1990s+), ordinary
  chondrites climb to ~92 %, and per-decade record counts explode from ~200 to ~18,000.
- **The geographic blind spot is modern.** All 13,754 unlocated records are finds and 98.7 %
  of them date after 1970; coordinate coverage drops from ~98 % (pre-1990) to 45.6 % in the
  2000s, so region/decade views describe a shrinking slice of the recent catalogue.
- **The detection floor collapsed.** The median recorded find fell from 13.0 kg (1900s) to
  10 g (1970s) — ~1,300× — while the median observed fall stayed at 1.2–4.4 kg in every
  decade: the record flood is small stones, not a busier sky.
- **Numbers and mass live in different regions.** Antarctica holds 69.1 % of geolocated
  records but 0.65 % of the mass; North America, Africa (rest) and Asia hold 70 % of the
  605 t total. Each environment also has a family signature (10): Arabia delivers Lunar
  stones, Antarctica the rare chondrites, old North-American collections the giant irons.

Full reasoning, numbers and caveats: [`docs/analysis.md`](docs/analysis.md).

## Data

`data/raw/Meteorite_Landings_cleaned.csv` — one row per recorded meteorite:
`name, id, nametype, recclass, mass (g), fall, year, reclat, reclong, GeoLocation, log10_mass`.
Known quirks: 13,754 records lack coordinates, 292 lack a year, 19 have `mass <= 0`.
